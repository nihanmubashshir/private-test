Decisions worth arguing with
Gym leads, weight follows
On a training day the session is the only thing you came for, so it sits above the weight card. On a rest day (A4) it collapses to one line and weight inherits the primary button.
One primary per screen
Gold fills exactly one button per frame. When the session is live it moves to Resume and the weight card drops to a bare number.
Log rows lost the fake range
A 38s run no longer reads 14:28 – 14:28. One start time, the duration right-aligned, day totals in the group header.
Stopwatch recedes when idle
In D3 the idle 0:00 is the same size but grey — the gold Start button is the focal point, not the placeholder.
Session screen can't be escaped by accident
No back chevron in C4 — a chevron-down Minimise instead, which keeps the clock running and drops the pill onto Home.
Direction is never coloured
Weight up or down both render in neutral grey. Green means live, gold means action, red means destructive. Nothing judges the number.
